4 / Backup & import

Export contains your accessible records as unencrypted JSON, not passwords, credentials, other users’ data, or a full database backup. Keep the file private. Import creates new records and checks access; it does not overwrite records with matching IDs.

What this application does—and does not do

Working record creation, editing, deletion, status tracking, agent assignment, bills, pay periods, hours, summaries, export/import, real-login integration and database policies are included. Dates use your browser’s local calendar; amounts use USD display. Upcoming totals are arithmetic summaries, not financial advice.

No bank connection, actual payments, automatic email reminders, payroll verification, autonomous AI runtime, external task execution, MFA onboarding or password reset. Agent “work” means organizing your entered records. Clearances protect cloud data, not static UI text.

Server entry logs cover requests to the supplied entry function, not every REST query or infrastructure event. Requests that never reach the server cannot be guaranteed logged. Rate limiting, log retention, dependency hardening, production security review, and live negative access tests remain required before sensitive/public use. Already viewed data cannot be remotely un-seen after grant revocation.
